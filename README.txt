README

This GitHub repository contains the experiment, materials, data, and analysis scripts for the paper "I don't know if naturalness ratings distinguish presuppositions from nonpresuppositions. Did Mandelkern et al. 2020 discover that they do?" by Judith Tonhauser and Judith Degen (published in Linguistics & Philosophy). 

The folder structure is as follows:
- /experiments/main/13_explicitIgnorance: This folder contains the experiment code. The experiment itself can be run by loading experiment.html.
- /results/main/: This folder contains the raw data and the clean data (under /data), the R scripts used to analyze the data (under /rscripts), the generated graphs (under /graphs), and the models (under /models).
- mandelkern-etal2020: This folder contains the data and R script to create panel (a) of Fig 2
- kalomoiros-schwarz2024: This folder contains the data and R script to create panels (b) and (c) of Fig 2
